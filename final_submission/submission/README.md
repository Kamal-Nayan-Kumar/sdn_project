## Quick start (from a clean checkout of `code/`)

Prereqs: Linux with `unshare -Urn` working (check with `unshare -Urn true`);
Python 3.12+; network access the first time you build the Mininet tool.

    python3 -m venv .venv
    .venv/bin/pip install -r requirements.txt
    bash code/scripts/setup-mininet.sh        # builds network-lab/bin/mnexec
    bash code/scripts/setup-ryu.sh            # clones the vendored Ryu tree
    cp .env.example .env                       # optional; LLM is off without a key

Then regenerate every result and figure in the paper with one command:

    bash code/final_submission/scripts/reproduce.sh

It starts the lab, runs all eight scenarios (S2, S3, S7, S8 as five
independent trials each), runs the test suites, and regenerates
`figures/` + `tables.tex`/`numbers.tex` from the recorded data. The whole
protocol fits in ~20 minutes.

(If `scripts/` don't work on your machine, it is because `reproduce.sh` calls
the exact equivalent paths inside `code/`; see "Exact commands" below.)

## Datasets

All datasets are synthetic (produced by this lab), except where stated:
- All latency measurements are real ping measurements inside the lab's hosts.
- Congestion is *emulated* with `netem` (synthetic delay injection) — stated
  plainly in the paper (§VII-B) and in AUDIT.md; it is not organic queueing.
- The background UDP stream is genuine offered load generated by the lab's
  own traffic generator (S7); it crosses the 80% utilisation threshold.
- The mininet lab topology, link delays and capacities are in
  `code/network-lab/topologies/multipath.py`; faults/seeds are in
  `code/network-lab/run_lab.py` and `code/final_submission/scripts/run_experiments.py`.
- No external data files are required. `.env` holds credentials and is **not**
  included; nothing here depends on an LLM (the headline evaluation is
  deterministic; see `data-llm/` for the model-active replication).

## Deterministic fallback vs. the model-active replication

The headline dataset (`data/`) was produced with no model endpoint configured
(the gates make every decision). `data-llm/` re-runs the identical protocol
with `qwen/qwen3.8-27b` on Groq active in intent parsing and narration; every
outcome is identical to the fallback run. Set an OpenAI-compatible key in
`.env` (`LLM_API_KEY`, `LLM_BASE_URL`, `LLM_MODEL`) to reproduce it.
